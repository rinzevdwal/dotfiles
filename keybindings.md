# Keybindings

## i3

### Moving Around

| direction | left | down | up | right |
| - | - | - | - | - |
| vim like | `j` | `k` | `l` | `;` |
| arrows | `` | `` | `` | `` |

| keys | function |
| - | - |
| `mod`+`direction` | move focus |
| `mod`+`shift`+`direction` | swap container |
| `mod`+`ctrl`+`direction` | move (floating) container |
| `mod`+`a` | focus parent |
| `mod`+`d` | focus child |

### Workspaces

| keys | function |
| - | - |
| `mod`+`0`-`9` | switch to workspace |
| `mod`+`,`/`.` | switch to workspace previous/next |
| `mod`+`shift`+`0`-`9` | move container to workspace |
| `mod`+`shift`+`,`/`.` | move container to workspace previous/next |
| `mod`+`m` | move workspace to next output |
| `mod`+`shift`+`m` | swap workspaces on output |

### Applications

| keys | function |
| - | - |
| `mod`+`q` | kill container |
| `mod`+`enter` | open new terminal |
| `mod`+`shift`+`enter` | open scratchpad terminal |
| `mod`+`space` | run desktop application |
| `mod`+`shift`+`space` | run executable |
| `mod`+`tab` | switch window |
| `mod`+`print` | run screenshot app |

### Container modes

| keys | function |
| - | - |
| `mod`+`r` | resize mode |
| `mod`+`e` | default |
| `mod`+`s` | stacking |
| `mod`+`w` | tabbed |
| `mod`+`h` | split horizontal |
| `mod`+`v` | split vertical |
| `mod`+`f` | full screen |
| `mod`+`t` | toggle focus floating |
| `mod`+`shift`+`t` | toggle floating |

### Session i3

| keys | function |
| - | - |
| `mod`+`x` | lock session |
| `mod`+`shift`+`e` | power menu |
| `mod`+`shift`+`r` | restart i3 |
| `mod`+`shift`+`c` | reload i3 config |

### Mouse

| keys | function |
| - | - |
| `mod`+`left-click`| drag container/floating |
| `mod`+`shift`+`left-click`| drag/swap container |
| `mod`+`right-click`| resize container |
